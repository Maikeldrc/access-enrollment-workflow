# Pylo devices

Pylo is one of ITERA's supported connected-device workflows when assigned/configured.
Never claim a patient has a Pylo monitor unless the assigned device record confirms it.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

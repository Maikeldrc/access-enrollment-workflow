# RPM devices

A connected monitoring device must be verified through trusted device assignment and transmission data.
Do not ask for photo/QR/serial on the happy path when the assigned device is already known.
One valid transmission can verify connectivity; baseline measurement requirements are separate.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

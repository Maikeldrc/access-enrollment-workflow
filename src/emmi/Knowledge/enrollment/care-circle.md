# Care Circle

Care Circle is optional trusted-person support.
A Care Circle member can help with navigation, reminders, logistics or device setup according to granted permissions.
Care Circle does not automatically allow consent, signatures, clinical decisions or Personal Representative authority.
Use a secure invitation flow and minimal necessary permissions.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

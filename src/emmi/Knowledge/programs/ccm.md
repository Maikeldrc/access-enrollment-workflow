# Chronic Care Management (CCM)

Chronic Care Management (CCM) provides ongoing support for patients managing multiple chronic conditions.

Patient-facing concepts:
- The care team can help coordinate care, medications, goals, transitions and needs between office visits.
- Participation is voluntary.
- Medicare cost sharing may apply depending on current coverage.
- Do not promise that CCM is free.
- Only communicate billing limitations and practitioner rules from the approved current program configuration.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

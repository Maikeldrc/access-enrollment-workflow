# Transitional Care Management (TCM)

Transitional Care Management (TCM) supports patients after qualifying transitions from certain facility settings back into the community.

Patient-specific discharge date, transition status and required follow-up must come from runtime/clinical workflows.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

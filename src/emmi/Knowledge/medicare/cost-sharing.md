# Medicare cost sharing

Never say a Medicare service is automatically free.
Deductibles, coinsurance or copayments may apply depending on the service and coverage.
For ACCESS, use the current expected beneficiary payment amount from runtime/configuration and verified secondary coverage before discussing a personalized out-of-pocket amount.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

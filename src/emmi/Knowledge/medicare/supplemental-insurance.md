# Supplemental insurance

Supplemental coverage may reduce some patient cost sharing, but do not promise it does so unless verified.
Use verified current coverage when answering personalized cost questions.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

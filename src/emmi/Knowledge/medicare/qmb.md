# Qualified Medicare Beneficiary (QMB)

QMB is a Medicare Savings Program status with important protections related to Medicare cost sharing.
Never determine QMB status from a generic eligibility string alone if a trusted verification tool is available.
Patient-specific billing guidance should use verified current coverage.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

## Patient answer (EN)

QMB stands for Qualified Medicare Beneficiary. It is a Medicare Savings Program that helps pay Medicare costs, and it comes with an important protection: if you are in QMB, Medicare providers are not allowed to bill you for services and items that Medicare covers, including deductibles, coinsurance and copayments. You may still get a bill for a small Medicaid copayment if one applies. Whether you have QMB is part of your verified coverage rather than something that can be assumed, so your care team can confirm it for you. If you ever receive a bill you think you should not have, keep it and tell your care team.

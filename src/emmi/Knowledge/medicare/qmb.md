# Qualified Medicare Beneficiary (QMB)

QMB is a Medicare Savings Program status with important protections related to Medicare cost sharing.
Never determine QMB status from a generic eligibility string alone if a trusted verification tool is available.
Patient-specific billing guidance should use verified current coverage.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

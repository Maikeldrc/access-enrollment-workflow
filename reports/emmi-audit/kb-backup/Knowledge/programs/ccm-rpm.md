# CCM + RPM

CCM + RPM combines ongoing chronic care support with connected physiologic monitoring when appropriate.

Present this as one coordinated care experience rather than two disconnected programs.
Avoid duplicating disclosures.
The next best action must come from the orchestration state.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

## Patient answer (ES)

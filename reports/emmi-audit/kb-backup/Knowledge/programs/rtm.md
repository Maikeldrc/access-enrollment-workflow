# Remote Therapeutic Monitoring (RTM)

Remote Therapeutic Monitoring (RTM) supports monitoring of certain non-physiologic therapeutic data when applicable.

Do not describe RTM as RPM.
Use the program configuration to explain what the patient is actually monitoring.

## EMMI response rule

Use plain, senior-friendly language. If the question becomes patient-specific, prefer trusted runtime data and approved tools over static knowledge.

## Patient answer (ES)

RTM, o Monitoreo Terapéutico Remoto, sigue ciertos datos terapéuticos que no son fisiológicos —por ejemplo cómo va con una terapia— cuando eso es aplicable a su cuidado.

## Patient answer (KR)

RTM, oswa Siveyans Terapetik a Distans, swiv sèten done terapetik ki pa fizyolojik — pa egzanp kijan w ap ale ak yon terapi — lè sa aplikab pou swen ou.
